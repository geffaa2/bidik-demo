# Bidik demo files

Hosting for the live demo of Bidik, a fictional photography school on WordPress and Paid Memberships Pro.
Open it at https://geffaa2.github.io/bidik-demo/ (the button loads `blueprint.json` into WordPress Playground).

- `blueprint.json`: installs the three zips below, turns on demo mode, builds the school and signs in as a demo member
- `bidik-membership.zip`, `bidik-theme.zip`: the plugin and the block theme (GPL-2.0-or-later)
- `paid-memberships-pro.3.2.2.zip`: the last build of Paid Memberships Pro published on WordPress.org (GPL), pinned because the plugin has since left the directory

The demo runs on a test gateway; no real payment is ever taken. Photos are CC BY-SA 4.0 (credits on the demo's footer).
